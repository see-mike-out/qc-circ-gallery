# Quantum Circuit Visualization Gallery

This gallery collects and provides 182 static and 12 interactive quantum circuit visualizations used for programming and presentation. This is a supplementary material for IEEE VIS 2026 paper, "A Design Space for Quantum Circuit Visualizations," which will be published in IEEE TVCG 2027.

## Access

Visit [https://see-mike-out.github.io/qc-circ-gallery](https://see-mike-out.github.io/qc-circ-gallery)

## Images

Most images are copyrighted, so we do not display the images. For publicly available cases, our gallery includes detailed instructions for how to find them from the original sources. Images that are removed/changed from the orignal sources can be available upon requests.
